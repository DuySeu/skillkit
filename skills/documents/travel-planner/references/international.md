# International travel reference

Read this before Step 3 when the trip is **outside Vietnam** (or multi-country).

## Booking platforms

| Region / type | Platforms |
|---------------|-----------|
| Global hotels | Booking.com, Agoda, Hotels.com |
| Whole home | Airbnb, Vrbo |
| Reviews & maps | Google Maps, TripAdvisor |
| Flights (if in scope) | Google Flights, airline sites — **do not book** unless user asks; quote reference fares only |

Cross-check lodging on at least two sources.

## Money

- Use the **destination currency** (USD, JPY, THB, EUR…)
- Set `trip.currency` in plan JSON
- Show approximate VND equivalent only if the user budgeted in VND

## Transport

- Airport transfer, rail pass, local metro — research per city
- Self-drive: IDP / local license rules; tolls and parking vary
- Ask: flights already booked? If not, note flight as a separate line item or pre-step

## Extra checks (mention in overview / warnings)

- Passport validity (6+ months common rule)
- Visa or visa-on-arrival requirements — **flag only**; do not give legal advice; suggest official embassy site
- Travel insurance for medical / cancellation if budget allows
- Public holidays at destination (affects price and closures)

## Search queries

- `[city] hotel [month year] price`
- `[property name] reviews`
- `weather [city] [dates]`
- `[country] public holidays [year]` when dates are fixed

## Time zones

Itinerary times are **local at destination**. Note flight times in departure and arrival zones if relevant.
